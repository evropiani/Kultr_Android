# Working rules

Rules from the owner of Kultr. They apply to every Kultr repository (web,
Android, iOS, website) and to every session.

- **Say first when something isn't possible.** If a request can't be done as
  asked (a limit of iOS, Android, the browser or a store, a missing API, a
  sideloading restriction), say so plainly before writing any code, with what
  is possible instead, and wait for an answer. Don't build a partial version
  first.
- **Deploy without asking.** Once a change passes its checks, push it to
  `main` and release it.
- **Settings exports leave out servers and passwords by default.** A server
  export never includes the username or password.
- **No model names** in commits, pull requests or code.
